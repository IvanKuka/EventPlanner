# Otázky pred novou špecifikáciou

Existujúce potvrdené požiadavky neopakovať: desktop, C#, lokálne dáta, Windows a oba Macy, unsigned release, bez povinného cloudu. Pred novou feature zisti scenár a konkrétny výsledok, rozsah MVP, zdroj pravdy dát, vedľajšie účinky, zrušenie/obnovu, súkromie, testy a platformy.

Otázku používateľovi polož vtedy, keď chýba produktová preferencia alebo oprávnenie. Technické API najprv over v kóde/primárnej dokumentácii; nepýtaj sa používateľa, aby hádal názov funkcie knižnice. Nezamieňaj návrh za potvrdený požadovaný rozsah. Rozhodnutie zapíš do relevantného spec a jeho dôsledky do testov a roadmap.
